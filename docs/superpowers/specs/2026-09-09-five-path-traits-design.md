# 五流派命格系统设计

## 目标

将 100 张命格从“修行速度、实力成长”等泛数值卡，重构为能决定一局玩法路线的构筑系统。玩家仍从五张候选中选择两张；两张命格既可组成同流派共鸣，也可跨流派形成自然联动。

## 全局约束

- 项目保持纯静态网页，不安装依赖、不增加构建步骤。
- 保留 100 张命格：白、蓝、紫、金各 25 张。
- 每个稀有度内，五个流派各 5 张。
- 命格数据中彻底移除 `cult`、`brk`、`cgt` 三种旧效果。
- 体质和事件仍可影响修炼突破与战力；本次只移除命格的旧泛数值。
- 白卡提供可靠的小收益，蓝卡提供条件收益，紫卡确立路线，金卡改变规则。
- 金卡不能直接保送顶级体质或证道成功。

## 五个流派

### 体质蜕变 `body`

围绕体质下限、后天蜕变和凡体逆袭。常用效果包括 `floor`、`bodyChance`、`bodyDao` 和 `swallow`。

同流派共鸣“百炼成道”：一生首次达到对应道蕴与境界条件时，进行一次后天体质蜕变，最高只提升一档且不超过九档。

### 道蕴悟道 `dao`

围绕初始道蕴、道蕴上限、成长倍率和溢出利用。常用效果包括 `dao`、`daog`、`daocap` 和 `overflow`.

同流派共鸣“道海无涯”：道蕴达到上限后，后续收益的 25% 暂存为溢出道蕴，最多暂存上限的 20%；冲击帝关时转化为判定优势。

### 气运机缘 `fortune`

围绕事件频率、定向高阶机缘、时代和坏事件转化。常用效果包括 `evf`、`evt`、`era`、`upgradeEvent` 和 `ward`。

同流派共鸣“否极泰来”：一生第一次成功触发的一、二阶机缘按高一阶结算道蕴奖励，不复制事件本身的特殊奖励。

### 天心证道 `tianxin`

围绕感悟天心、保底、融合门槛和大道压制。常用效果包括 `xin`、`xinPity`、`dlm`、`ignoreSuppression`。

同流派共鸣“天心相照”：进入准帝境后，每个未感悟天心的年份积累保底值；触发后清空。保底只提高感悟概率，不直接赠送天心。

### 帝路生存 `imperial`

围绕寿元、化险为夷、帝关重修和失败代价。常用效果包括 `life`、`ward`、`retry`、`retryKeep` 和 `zhx`。

同流派共鸣“帝路不绝”：第一次帝关失败进入重修，不立即死亡；重修仍会损失实力、寿元和部分道蕴，不能无限触发。

## 卡牌结构

每张命格包含：

```js
{
  id: 'w01',
  name: '百炼凡骨',
  color: 'w',
  path: 'body',
  fx: [['floor', 2], ['dao', 2]]
}
```

`path` 必须是五个流派之一。所有效果都由统一描述器生成文案，不在 HTML 中预填卡牌内容。

每个流派在每个稀有度安排五种角色：

1. 稳定起点；
2. 成长引擎；
3. 条件转化；
4. 风险防护；
5. 与其他流派连接的桥梁牌。

卡牌名称允许全面调整，使名称、流派和实际效果一致。

## 组合规则

- 两张同 `path` 命格激活该流派共鸣。
- 两张不同流派不额外授予固定套装奖励，避免十种跨流派组合膨胀。
- 跨流派通过效果自然联动，例如气运提供高阶机缘，道蕴牌将高阶机缘转化为道蕴。
- 卡牌选择界面显示流派徽标；选择第一张后，候选卡展示“同流派共鸣”提示。
- 开局日志明确显示两张命格及激活的共鸣。

## 数据与引擎边界

- `data.js`：持有 100 张卡、流派元数据、效果文案和静态校验所需常量。
- `sim.js`：聚合效果、判断共鸣，并在年度推进、事件结算、天心感悟和帝关判定处消费机制状态。
- `game.js`：只负责展示流派、选择态和共鸣预览，不复制模拟规则。
- `index.html`：保持空的动态卡牌容器，不写死候选卡。
- `tests/trait-system.test.js`：使用 Node 内置 `assert`，不引入测试框架。

## 平衡边界

- 白卡单项收益约为对应金卡稳定收益的 15%–25%。
- 蓝卡强于白卡，但条件收益不能稳定超过紫卡。
- 紫卡应足以确立路线，但需要另一张牌或局内事件完成闭环。
- 金卡提供独特规则，数值收益应与紫卡接近，强度来自玩法改变。
- 同流派共鸣等价于约半张紫卡，鼓励专精但不压制跨流派组合。
- 帝关重修始终有真实代价；任何组合最多提供两次帝关尝试。

## 验收标准

- 100 张命格数量不变，四种稀有度各 25 张，五流派各 20 张。
- 每个“稀有度 × 流派”组合恰好 5 张。
- 命格数据与描述中不存在修行速度、实力成长、初始实力及旧类型。
- 五种同流派组合均能激活正确共鸣。
- 不同流派不会误触发共鸣。
- 共鸣的关键效果有自动化回归测试。
- 所有脚本通过 `node --check`，测试脚本退出码为 0。
