# 事件与素材原著核对（《遮天》）

核对口径：以原著设定为准，对命名实体用遮天百科/维基交叉核对。拿不准或原著未点名的，一律归为「泛设定」并只用于低阶事件，不混进极道帝兵、不死药这类强设定池。素材池落在 [events-pools.js](events-pools.js)。

### 不死神药 `T4_HERB`

原著设定：不死药共三十株，皆为乱古时代陨落的仙所化，核心作用是让人再活一世。

保留：真龙不死药、九妙不死药、人形神药、麒麟神药、悟道古茶树、玄武神药、神凰不死药、蟠桃神药、白虎神药、朱雀不死药、混沌青莲、扶桑神树、人参果神药。

| 原条目 | 处理 | 原因 |
| --- | --- | --- |
| 生命古树 | 删除 | 原著无此神药 |
| 菩提古树 | 删除 | 非遮天不死药，疑似串了别的作品 |
| 人参果树 | 改为「人参果神药」 | 统一为神药形态的称呼 |

设定约束已写入契约：不死药只能续一世，不能量产；玄武神药是延寿最强的「万岁神药」；九妙不死药被狠人大帝分为九株种在荒古禁地。

### 秘境 `T4_MI` / `T3_MI` / `T2_MI`

T4 全部是原著禁地与顶级险地（荒古禁地、太初古矿、不死山、神墟、仙陵、轮回海、葬天岛、紫山、万龙巢、化仙池、圣崖、青铜仙殿、仙府世界），补入太阴古星与生命禁区外围。T2 池为泛设定的低阶险地，保留。

### 纪元 `AGES`

《遮天》原著明确记载的纪元顺序是：乱古 → 冥古 → 神话 → 太古 → 中古 → 荒古，叶凡所处的是后荒古时代。

初版把「上古时代」「乱古时代」当成可出生纪元，两处都错：

| 原条目 | 处理 | 原因 |
| --- | --- | --- |
| 乱古时代 | 移出 `AGES`，改入 `LEGEND_AGES` | 乱古纪元是《完美世界》石昊的时代，遮天只在泰山回溯、张百忍口述中提及，不是遮天角色能出生的纪元 |
| 上古时代 | 删除，补回「中古时代」 | 「上古」是读者混用的泛称，原著记载的过渡纪元是中古 |
| —— | 新增「后荒古时代」 | 叶凡所处纪元的正式名称 |
| 冥古时代 | 归入 `LEGEND_AGES` | 遮天只说它「比太古还古老」，信息过少，仅作传说引用 |

修正后 `AGES = ['神话时代', '太古时代', '中古时代', '荒古时代', '后荒古时代']`，另设 `LEGEND_AGES = ['冥古时代', '乱古纪元']` 只用于残碑、帝痕、追溯类文案。新增 `eraPair()` 保证「自甲代到乙代」这类句式按时间先后取两个不同纪元。

**同名陷阱**：荒古时代另有一位名为「乱古」的大帝（虚空大帝之后、无始大帝之前证道），与乱古纪元同名但毫无关系。因此 `T4_CHUAN` 中的「乱古大帝传承」是原著条目，保留。

### 其他新增池

`SECTS`（姬家、姜家、摇光圣地、太玄门、瑶池、大夏皇朝等原著势力）、`REGIONS`（北斗四方与星空古路分段）、`RIVAL_TITLES`（圣子、圣女、古族天骄等泛称）。天骄一律用泛称加动态生成，不杜撰具体帝号。

## 二、事件逻辑核对

| 设定 | 处理 |
| --- | --- |
| 荒古圣体准帝九重天即大成圣体、极道至尊 | 不再需要额外的「大成」仪式；无帝之世战力约 160 万起，近乎宇宙第一 |
| 圣体的诅咒来自禁区至尊，不是天意 | 事件文案统一按此口径，动机是圣体太容易成准帝、妨碍黑暗动乱 |
| 圣体成帝万古仅叶凡做到 | 光秃约 2%~4%，合适金卡可抬到约 30%，不设保送 |
| 成帝前不得获得奇异世界坐标、仙源、太初命石 | 这三样只在帝者机缘里出现；`qiyishijie` 事件只给传闻不给坐标 |
| 不死药只能续一世 | `busiyao` 设 `maxCount: 1`，`g.deathless` 只能用一次 |
| 大帝证道后其道法更受天心青睐、修行更快 | 新增帝者片段 `dao_prosper` 体现 |
| 不死天皇无法被单人击杀 | 见下 |
| 太古/乱古万族、圣灵、妖族同样能走到极高层次 | 体质与种族事件覆盖妖族、古族、圣灵路线 |

## 三、不死天皇规则修正

原实现的问题：世数抽取与玩家处境无关，早期入界也可能撞上二世或八九世；而且战力接近时允许单人当场击杀。

修正后：

- 世数由入界时点决定。`undeadEmperorMean(worldYear, lifeNo) = 3.8 + min(1.6, (lifeNo-1)*0.42) + min(1.8, worldYear/1500000*1.8)`，σ = 1.1。
  第一世入界时三至五世合计约 85%，八九世合计约 0.2%；拖到第九世、万古历 360 万年后入界，六至八世合计约 90%。
- 红尘仙级天皇是极端离群值，早期概率约 0.2%，随年份和世数最高升到 8%。
- 结果拆成三种：**逃脱**、**逼退**、**斩杀**。
  - 逃脱按战力差判定，差距越大越难。
  - 逼退需要 `undeadRepelChance(g) > 0`，即战力达到对方 85% 以上，再叠加道蕴与巅峰体质加成，上限 80%。先天圣体道胎加满道蕴可以稳定相持并把他打退，追杀因此中断，但他会涅槃后卷土重来。
  - 斩杀只有 `canSlayUndead(g)` 为真时才可能，即必须实际遇到无始与天皇的对峙局势，并选择与无始联手。
- 日志分别写「逃脱追杀」「逼退天皇」「与无始联手斩杀」，不再把逃脱写成击杀。
